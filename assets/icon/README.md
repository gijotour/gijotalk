# 앱 아이콘

`icon.svg.html` 이 원본입니다. 크기를 바꾸거나 색을 고칠 때 여기를 고치고
헤드리스 크롬으로 512px 를 렌더한 뒤 나머지 크기를 뽑습니다.

```
# 512 렌더 (Playwright/헤드리스 크롬으로 #icon 요소를 스크린샷)
# 그다음
sips -Z 192 icon-512.png --out icon-192.png
sips -Z 180 icon-512.png --out icon-180.png
```

## 지킬 것

- **배경을 꽉 채울 것.** 안드로이드 maskable 아이콘은 가장자리를 원형으로 잘라냅니다.
  여백을 투명하게 두면 잘린 자리가 검게 남습니다.
- **그림은 가운데 원(지름 80%) 안에.** 원형·스퀘어클·iOS 라운드 어느 마스크로
  잘려도 살아남는 영역입니다.
- **요소는 둘까지.** 192px 에서 형태가 남아야 합니다. 글자는 넣지 않습니다.

## 상징

지도 핀(여행지) + 필리핀 8각 태양(국기 문양). 배경은 브랜드 코랄
(`--color-brand-vivid` #FF6B4A 계열), 태양은 `--color-accent` (#FFB800).
